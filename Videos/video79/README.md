# Scope
This is video 79 on a MicroPython/LVGL embedded solution. In this video, we try a test program on LVGL 9.5.0.  We provide firmware for the four standard RPI models and two variants.  We test the firmware using a LVGL program using the Chart widget.  Our test rig is a Pico2W (RP2350) with an integrated ILI9341 Display.  We also demonstrate gathering weather data from the Open-Meteo web site.  

You can fetch the firmware and programs from our GitHub site, and begin using them immediately.  

In this video, 
 - Demonstrate LVGL chart program.
 - Demonstrate Open-Meteo API and web site.
 - Discuss the hardware configuration.
 - Present the new firmware.

The code for this video is available at the GitHub site:
