# Scope
This is video 85 on a MicroPython/LVGL embedded solution. ILI9488 is a 320*480 pixel display. In this video, we try several ILI9488 displays, and investigate why some "fail" and others work in our MicroPython LVGL environment.  We develop a MicroPython driver and a proof of concept driver for the displays that "fail". 

We use firmware published recently (but it works similar to a previous file.)   Our Test Rig uses a RPI Pico 2W USB board because it has more memory then the earlier models. You can fetch the firmware and programs from our GitHub site, and begin using them immediately.  Most of our displays have XPT2046 touchscreens (so we demonstrate touch functions for it.)

In this video, 
 - We demonstrate our working ILI9488 driver for "good" displays
 - We discuss the Test Rig and wiring
 - We explain why some display that "fail" for MicroPython LVGL
 - We discuss the solution and demonstrate.

The code for this video is available at the GitHub site:
https://github.com/kwinter745321/PicoLVGL/tree/main/Videos/video85
