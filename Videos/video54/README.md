# Scope
This is video 54 on setting up MicroPython setting up LVGL on RPI Pico USB Board.  We demonstrate two GUI code examples. We discuss the hardware and wiring.  We mount the RPI Pico USB Board and the ILI9341 display on a breadboard.

In this video, 
 - Demonstrate our slider and button examples
 - Present the display and the wiring
 - Discuss the GitHub files
 - Walk through the code

The code for this video is available at the GitHub site:
https://github.com/kwinter745321/PICOLVGL/tree/main/Videos/Video54


The Base Board for the Raspberry Pi Pico is available for purchase:

Additional firmware containing the latest MicroPython with LVGL and ulab are also at the GitHub site.
